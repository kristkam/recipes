# recipes

Recipe collection app built with React, TanStack Start, and TanStack Router.

## Project Setup

```sh
pnpm install
```

### Development

```sh
pnpm dev
```

The app is served under `/recipes/`.

### Production Build

```sh
pnpm build
pnpm preview
```

### Type Check

```sh
pnpm type-check
```

### Unit Tests

```sh
pnpm test:unit
```

### End-to-End Tests

```sh
pnpm exec playwright install
pnpm test:e2e
```
